# Mobile Firebase

Aplicativo Android desenvolvido em Kotlin, com telas XML e autenticação pelo Firebase.

## Funcionalidades

- Login com e-mail e senha.
- Cadastro com confirmação de senha.
- Tela inicial com boas-vindas e e-mail da conta.
- Sessão mantida ao reabrir o aplicativo.
- Botão para sair da conta.

## Como executar

1. Abra o projeto no Android Studio.
2. No Firebase, registre um app Android com o pacote `com.laurencekl.mobilefirebase` e ative o login por e-mail e senha.
3. Coloque o arquivo `google-services.json` na pasta `app`.
4. Sincronize o Gradle e execute em um celular ou emulador com Android 12 ou superior.

O arquivo `google-services.json` não está incluído no repositório.
